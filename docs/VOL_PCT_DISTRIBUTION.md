# Research: Распределение vol_pct по активам (Задача 1.1)

**Дата:** 2026-08-29
**Статус:** preregister-данные для Задачи 1.2. Код прод-путей не менялся.
**Скрипт:** `scripts/research/vol_pct_distribution.py`
**Источник данных:** `data/market_data_mt5.sqlite`, таблица `ohlcv_m15`, бары до **2026-08-08 включительно**.

## Методология

- `vol_pct = atr / close` — та же величина, которую читает
  `adaptive_holding_period()` (`labeling/label_generator.py`) при
  `adaptive_holding=true`.
- ATR: period=14 (`config/config.yaml: features.atr_period`), реализация
  `features/indicators.atr` — EWM true-range, `alpha=1/14`,
  `min_periods=14`. Первые 14 баров каждого актива (NaN warm-up ATR)
  исключены из статистики.
- Читаются все M15-бары символа в диапазоне; временные пропуски (выходные)
  обрабатываются индикатором как есть — без интерполяции (тот же
  контракт, что в прод-пайплайне).

## Выводы

1. **Гипотеза подтверждена.** Пороги 0.02 / 0.01 для XAUUSD
   недостижимы: максимум `vol_pct` за всю выборку — **0.015956** (≈1.6 %),
   т.е. ветка `vol_pct > high_vol_pct` (horizon // 4) никогда не
   срабатывает, а ветка `> mid_vol_pct` (horizon // 2) срабатывает на
   0.25 % баров (≈157 баров из 63k). При включении
   `adaptive_holding=true` с текущими порогами адаптив фактически
   неотличим от `false` — «identical outcome» предсказуем.
2. Для EURUSD/GBPUSD пороги ещё дальше: p99 ≈ 0.0016 / 0.0014, max
   0.0033 / 0.0024 — оба продовых порога превышаются **нулём** баров.
   Активы ~3 раза «спокойнее» XAUUSD по vol_pct.
3. XAUUSD и FX-пары живут в разных режимах волатильности: p95 XAUUSD
   (0.003283) почти в 3 раза выше p95 EURUSD/GBPUSD (~0.00104–0.00106).
